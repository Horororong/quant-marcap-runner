### A — 2022년 1분기 보고서

[공식 KIND 문서](https://kind.krx.co.kr/external/2022/05/13/000034/20220513000042/11013.htm)의 표지에서 발행회사 **주식회사 셀트리온헬스케어**,
제23기 분기보고서, 대상기간 2022-01-01~2022-03-31, 표지 제출일 2022-05-13을 직접 확인했다.
문서 식별자는 KIND 외부 경로의 `20220513000042/11013`이며, 이를 별도로 확인한 DART 접수번호로 표현하지 않는다.

정확한 위치:
**VI. 이사회 등 회사의 기관에 관한 사항 → 3. 주주총회 등에 관한 사항 → 바. 주주총회 의사록 요약**.
2020-03-27 정기주총 행의 안건 목록에 주식배당안 승인 건이 있고, 같은 부모 행의 결과는 가결이다.
웹 추출 위치는 3951~3961행이다. 날짜·안건·결과의 짧은 원문 셀을 `evidence.json` A에 보존했다.
셀 단위 문자열을 읽은 뒤, 결과가 다음 연도 행에 속한 것은 아닌지 부모 행의 날짜와 함께 대조했다.

따라서 **주총 승인 사실을 사후 공식 보고서로 확인**할 수 있다.
원래 서명된 의사록이나 2020년 당시 주총 결과 공시 자체를 새로 취득한 것은 아니며,
해당 사실을 2019년 투자자가 이미 알 수 있었다는 뜻도 아니다.

### B — 2023-03-20 제출 사업보고서

[공식 KIND 문서](https://kind.krx.co.kr/external/2023/03/20/000902/20230320004068/11011.htm)의 표지 발행회사는 A와 동일하다.
제23기 사업보고서의 대상기간은 **2022-01-01~2022-12-31**, 표지 제출일은 **2023-03-20**이다.
문서 식별자는 외부 경로의 `20230320004068/11011`이다. “2023년 제출”과 “2022 회계연도”를 구분한다.

정확한 위치:
**7. 증권의 발행을 통한 자금조달에 관한 사항 → 7-1. 증권의 발행을 통한 자금조달 실적 →
지분증권의 발행 등과 관련된 사항 → 가. 증자(감자)현황**.
표 기준일은 2022-12-31이며, 단위는 원·주다.
웹 추출 5135~5145행에서 열 제목을 확인한 후 **2020-03-27 / 주식배당 / 보통주 / 7,116,148주** 행을 읽었다.
그 행 전체의 짧은 원문을 `evidence.json` B에 보존했다.

이 날짜의 열 제목은 **주식발행(감소)일자**이다.
따라서 발행 이력은 확인되지만 **증권계좌 입고일·KRX 추가상장일·최초 거래 가능일은 확인되지 않는다**.
행에 있는 1,000원 금액은 주당 액면 및 발행가액 열이며, 시세나 배당락 기준가격이 아니다.

## 기존 배당안과의 연결

Stage9 E03에 보존된 2020-03-12 소집공고의 제6호 의안은
같은 발행회사의 2020-03-27 주총에 상정된 5%·보통주 7,116,148주 배당안이다.
A는 해당 날짜·안건의 가결 기록을, B는 같은 날짜·주식 종류·수량의 발행 기록을 추가한다.

연결 성격은 **배당안 → 승인 이력 → 발행 이력의 사후 사실 대조**다.
A의 해당 행이 배정률·수량을 직접 재기재하는 것은 아니므로 두 문서의 증명 범위를 합쳐 과장하지 않는다.
이 연결을 원공시·정정공시의 전체 버전 체인 인증으로 표현하지 않는다.
사후 공식 보고서는 사건 검증 근거로만 사용하며 2019년 신호 입력에 소급 투입하지 않는다.

## 남은 세 가지 조사와 중단 지점

추가 조사는 지정된 세 주제의 공식 도메인 검색 6개와 법규 원문 열기 1회로 제한했다.
2020-03-27 발행일을 입고나 거래 가능일의 대용으로 사용하지 않았다.

1. **2019-12-27 배당락 통지와 54,600원 기준가격 — UNVERIFIED.**
   해당 사건의 공식 현물 통지와 일별 기준가 원장을 확보하지 못했다.
   기존 수치적 정합성은 공식 근거로 승격하지 않았다.
2. **당시 코스닥 현물 기준가격·호가단위 규정 — UNVERIFIED.**
   검색된 2021년 코스닥 세칙 URL은 2019년 유효본이 아니다.
   이를 열어 이력·관련 원문 경로를 확인하려 했으나 아래 접근 오류가 발생했다.
   후대 규정, 파생상품 규정 또는 추정 반올림을 대체 적용하지 않았다.
3. **실제 주식 입고 및 거래 가능일 — UNVERIFIED.**
   실제 배당주식 전자등록·입고 확인과 해당 KRX 추가상장 원문은 확보하지 못했다.
   이전 비공식 2020-04-24 언급도 인증 근거로 쓰지 않았다.

실패 URL:
`https://law.krx.co.kr/las/RefBon.jsp?lawid=000113&lawkd=B&pubdt=20211027&pubno=0000019900`

도구 오류 원문: `(400) Timeout fetching`.
이는 웹 도구의 취득 실패이며 공식 서버가 HTTP 400을 반환했다고 직접 확인한 값이 아니다.
쉘 명령이 아니므로 프로세스 종료코드는 해당 없음이다.
이전 Stage9와 같은 `law.krx.co.kr` 사이트에서 다시 실패했으므로,
해당 URL 재시도 **0회**, 오류 이후 추가 원천 수집 **0회**, 새 수집 코드 **0개**로 중단했다.
KIND 보고서 A/B 읽기는 성공했으므로 KIND 전체가 차단됐다고 표현하지 않는다.
터미널 네트워크에는 KIND/법규 호스트 허용과 자격증명 binding이 없으며 우회하지 않았다.

필요한 원천자료는 (1) 해당 091990 배당락 통지·공식 시세/기준가 원장,
(2) 2019-12-27 적용 코스닥 현물 세칙·별표·호가단위 및 개정 이력,
(3) 실제 배당주식 입고 확인·추가상장 통지이다.
공식 아카이브 접근권 또는 해당 공식 파일 제공이 필요하며, 구매·별도 계약의 필수 여부는 이번 조회로 확정하지 않았다.
추가 추정 데이터나 수집기를 만들지 않는다.
