## 공통 구현

- 연도별 완전한 신호 단면을 기존 scorer/provider로 읽고 공통 top_n/deciles로 선정한다.
  이후 선택된 코드와 검증된 승계 코드만 가격 진단용으로 투영한다. 현 생존종목 목록,
  알려진 문제를 피하는 제외 조건, 기간 축소는 사용하지 않는다.
- 예정 양수 보유 코호트·미정산 권리·t+1 체결을 추적해 구체적인 사건·날짜·종목·
  차이·원 신호·필요 조치를 반환한다. 수량·NAV·drift·비용은 preflight에서 계산하지
  않는다. 첫 차단 이후의 후보도 요청된 코호트를 조건부로 따라간 진단이며 실제 실현
  보유나 이후 실행 인증이 아니다. 최종 수량·현금·거래 검사는 PROJECT에 남는다.
- 데이터 부재, 원천 증거 미확인, 모집단 부족, 거래불가 실행 제약, 연구 가정,
  계좌/투자 인증 요구를 구분한다. 실제0거래량 주문과 확인된 모집단 부족은 요청 계약의
  FAIL이며 나머지 미확인 원천 사건은 UNVERIFIED다. 코드가 실행됐다고 원천을PASS하지 않는다.
- 공개 workbench의check/run은 이 계획 노출 preflight를 사용한다. 기존 preflight의
  source-only 기본 API는 보존하고 `--inspect-planned`로 명시적으로 확장한다.
- 선택 코드·검증된 승계 계보로 연구 사건 로딩 범위를 정해, 전혀 보유하지 않는 법인의
  미완료 배당 생애주기가 무관한 상위1종목을 차단하지 않도록 했다. 신호 모집단은 그대로다.
- 저장된 준비도·실행 실패는 구조화 JSON과 `issues --saved-run`으로 재사용한다.
  옛 진단은 자동 면제·수익률 보정·새 실행 승인으로 사용하지 않는다.
- 공식 분할 기준가 대비 가격 등락률 검사와 분할 주식수 기반 경제적 수익을 공통 엔진과
  독립 registry reconciliation에서 분리했다. 정확한 종목·효력일·선공개 증거·파일 SHA를
  검증한 split에만 선택적으로 적용한다. 경제적 수익·NAV를 exchange percentage로 덮어쓰지
  않으며 일반 거래일1bp·미등록 사건 차단·기존 계좌/금융PIT 게이트를 유지한다.
- machine contract26, workbench2, planned readiness1, PROJECT execution v2-16-exec-6,
  corporate registry8, reconciliation2. CURRENT 성과 소유자 v2-18은 변경하지 않았다.

## 실제 수량·현금 검증

2020년 두 배당의2021년 승인·가상 상장일 정산을 실제85거래일씩 대조했다.
Gross/Net별 보유량에서 권리가 생성되며 입고 전 매도·신규 매수·재균형을 포함한
총510독립 장부행이 통과했다. 최대 원화 오차는 각각1.4551915228366852e-11,
9.094947017729282e-12이며 허용 오차는 기존 통화 단위1e-5다. 작은 구간의 기능 시험이며
원래2년 또는7년 전략의 축소 성공이 아니다.

카카오 실제7거래일·14장부행의 기능 검증은 다음을 분리했다.

- 마지막 거래 종가558,000원,분할 후120,500원,실제주식수배수5를 적용한 보유 수익률:
  `5*120500/558000-1 = 0.07974910394265233`.
- 공식112,000원 기준가 대비 가격 등락률:
  `120500/112000-1 = 0.0758928571428572`.
- 원자료 ChangesRatio7.59%와 후자의 차이는0.0714285714278895bp로 기존1bp 이내다.
  전자는 같은 수익률이 아니므로1bp 이내로 강제하지 않는다. 실제 장부 최대 오차는
  1.8189894035458565e-12다. 입고/분할 처리에 새 수익·매매비용을 중복 인식하지 않았다.

별도 상위1종목2019–2025의1,719거래일, Gross와두Net을 포함한5,157독립 장부행은
최대1.6391277313232422e-7원 오차로 통과했다. NAV와CURRENT성과5개 신규 파일 SHA를
numeric_manifest.json에 최초 고정했다. 한국어와JSON의 NAV·목표비중·CURRENT성과는
바이트 동일하고 선정 값도 동일하다. 임의 팩터명으로 생긴 audit 헤더만 대응한다.

## 고정 회귀와 실패 기록

이전 세 성공 실행151개 파일을 전용 ZIP(8,623,247bytes,
SHA256 c1da4ff846d0f4524044ad57ba79fd61803e4037dc22c89dad80800c52d65d62)과
regression_baseline.json에 먼저 고정했다. 이 기준은 새 결과로 갱신하지 않았다.
130개 고정 파일은 바이트 일치,9개 plan/preflight는 명시적 계약 변경을 별도로 대조했다.
plan은 engine/registry/machine버전3필드만 변경을 허용하며 그 밖의 값은 모두 동일하다.
preflight는 같은 fingerprint·요청기간·거래일·행수·벤치마크에 계획 노출 검사를 추가했다.
실행시각·절대경로를 포함한12개 외피는 보존하되 바이트 회귀 기준으로 쓰지 않는다.
이전15개 NAV/성과 고정 해시는 전부 일치한다.

로컬에서는 기존19명령 회귀와기존19명령 연구 환경 회귀를 실제 실행했다.
최종 CI는 원래DART E2E를 포함한 기존19명령, 고정 결과 회귀, 신규 경계 시험,
실제 배당/분할 장부, 전체7년 상위1종목 및 한국어 실행, 실제 Chromium 상호작용,
518/64·60원문 복원 검사에 연결했다. CI결과·GitSHA·RunID는 실제 Actions와
stage16-continuous artifact의summary.json 및browser_verification.json으로 확인해야 한다.
이 문서만으로 미실행 CI를 성공이라고 주장하지 않는다.

초기 로컬 종료는 숨기지 않고local_validation에 보존했다.
- 고정 환경의 `-I`가 script import 경로를 제거한 ModuleNotFoundError는 명시적인
  repository scripts 경로를 주입해 해결했다. 시스템Python·설치를 사용하지 않았다.
- 선행 회귀 완료 전 종속 비교를 시작한 FileNotFoundError는 완료 전제 검사를 추가했다.
- 긴 한국어/JSON 선정 CSV의 팩터 audit 이름 차이를 값 차이로 본 AssertionError는
  감사기 결함이었다. 팩터 정의 전항목 일치 후 이름만 매핑하고 모든 셀을 check_exact로
  재검증했다. 두 실행·원본 CSV·기존 기대값은 수정하지 않았다. 완료된 실행은 입력
  SHA·실행상태·독립 장부를 확인한 뒤 최종 비교만 재개했다. CI는 전 과정을 새로 실행한다.

## 남은 장애와 다음 최소 작업

LG의2021-05-03 주문은 자료를 더 얻어도 원래t+1종가 거래불가라는 사실이 달라지지
않는다. 확인한 공식 거래정지와원자료0거래량을 버리고 체결했다고 만들 수 없다.
현재 규칙의 전체10분위 NAV는 계속 차단한다. 거래정지 시 미체결 주문·보유 동결·
후속 주문 충돌·재개 후 체결을 처리하려면 원래 결과와 별도의 명시적 실행 계약/DSL이
필요하다. 원래 체결일을 조용히 미루지 않는다. 이후 LG/LX와같은1:N분할 권리,
후속 배당·유상/무상·합병의 독립 근거와 수량 계약도 필요하다.

현재 예정 코호트에서는 LG 이후의 미등록 기준가/권리 변동과091990 소멸 후 관측 부재
등도 남는다. 전체 목록은results/original2019_2025_readiness.json에 있다. 이 목록을
자동 기업행위로 등록하거나 이후 전 구간 검증 완료로 간주하지 않는다.
2001년4종목 부족은 모집단 정의의 한계이며 데이터 결측으로 처리하지 않는다.
별도 장기 상위1종목도2018-05-02의삼성전자 매도 거래불가가 있어 아직 전체 실행을
승인하지 않는다. 공식 휴지/분할 증거와 별도 미체결 주문 계약이 다음 공통 개발의 입력이다.

2026년은 별도 UNVERIFIED다. XKRX4.13.2가 예상한6/3·7/17이 보존 관측에서 없고,
KOSPI 벤치마크는9/17 이후 필요한 날짜가 없다. 정확한 시장·일자별 진단은
results/separate2026_readiness.json에 남겼다. 현물 공식 달력과 원지수 자료 없이는
평일 계산·보간·기간 축소로 인증하지 않는다.

이번 수집에서 권한·접근 실패는 없었다. 사용자에게 원문 복사를 요구하지 않는다.
현재 반드시 사용자에게 제공받아야 할 파일은 확인되지 않았다. 고정된 원래 체결 규칙과
