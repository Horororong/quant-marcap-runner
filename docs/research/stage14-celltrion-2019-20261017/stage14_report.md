## 실제 가격과 공통 장부에서 완료한 범위

Stage12 공식 KRX8응답/12필드 PASS를 재사용했다. 시세를 다시 다운로드하지 않았다.
068270의2019-12-26종가189500,12-27종가184000,등락률1.66%다.

- 원시 종가수익률 =184000/189500−1 = **−2.9023746701847%**.
- 공식 기준가 수익률 =184000/181000−1 = **1.6574585635359%**.
- 공식1.66%와 차이 **0.25414364640884bp**, 공통 validate_market_reference의 기존1bp 조건 PASS.
- 배당권리 포함 수익률은 `(기존주식가치+권리평가액+현금−비용)/전일NAV−1`이다.
  조건부 권리5%에 임의로 당일 종가를 곱하거나 세후 값으로 간주하지 않았다. 실제 경제적 수익률은 null/U다.

verify_event.py는 기존 파서 결과가 아니라 원본 DART member를 직접 독립 확인하고,
KRX 원래 가격행·보존 Stage11 기준가 관찰을 공통 가격검증 함수와 대조한다.
Stage11 기준가의 SHA는 authored observation JSON 해시이며 원본 HTTP해시라고 하지 않는다.
공통 장부에는 명시적 기능검증 계좌100주를 사용했다(원래 전략이나 실제 계좌 아님).
배당락 전 보유100주는5주 권리를 만들지만 **당일 권리 mark 누락 오류**로 원자적 차단되며
개시 주식·현금·권리 상태가 그대로다. 배당락일 개시0주에서 새100주 매수는 권리0주임을
실제184000원 입력으로 확인했다. 이 신규매수 probe의 거래비용0은 기능검증 설정으로만 표시했다.
이것을 승인·입고·리밸런싱·Gross/Net 전체 사건 검증 성공으로 세지 않는다.

기존 합성 통합 장부/단주/비용/승인/취소/입고/거래 가능 전환 회귀는 별도로 재실행했다.
