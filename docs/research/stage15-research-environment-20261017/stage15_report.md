# Stage15 — 실제 연구 환경 연결

원격 기준 eea1887309911a607b3bd20b002da66b3e48f0ec, 기존 수정 브랜치 유지.
**원래 2019~2020 시총10분위를 전체 실행했다.** 한국어 항목 문법→등록된
DSL→preflight→공통 PROJECT→비용 전/후 NAV→CURRENT 보고서도 실제 실행했다.
이는 연속수량·배당세 전 **RESEARCH_ONLY** 모델 결과이며 투자 PIT 승인이나
실제 증권계좌 인증이 아니다. Stage6 투자 PIT0/6과 기존 운영 게이트는 유지한다.

## 해결한 실행 공백

조건부 배당권리에 관측 시장가격이 없다는 것은 평가 계약의 미선택 문제다.
원공시 배정률·기준일·공식 기준가·승인·추가상장은 역사적 사실로 별도 확인했다.
기본 계약은 미입고 권리를 당일 기초주식 종가의 명목 주식등가로 평가한다.
계수1.0은 승인 확률·공식 관측값이 아니다. 0.9 계수와 상장 후1세션 정산을
각각 별도 fingerprint의 사전 정의 시나리오로 검증했다.

공식 추가상장일 종가에 가상 계좌에서 정산하는 모델을 명시했다. 개인계좌
실제 입고로 표시하지 않는다. 연속수량은 단주를 비례 배정하고 단주 현금·개인
원천징수는 복원하지 않는다. 기존 정수계좌·원천자료·PIT 계약은 완화하지 않는다.
Net에는 기존 거래비용만 반영한다. 배당세 후 성과라고 해석할 수 없다.

승인 전 조건부 상태, 승인 공개 후 인식, 취소, 권리 잔존, 거래 가능 주식과
비유동 권리·수량, 현금 재원, Gross/Net별 보유량, 가치 중복 방지는 기존 공통
장부/목표비중 실행에 연결했다. 입고 정산은 권리→주식 전환만 하며 새 수익이나
거래비용을 만들지 않는다. 원본 시세와 ChangesRatio를 덮어쓰지 않는다.

## CURRENT 성과와 민감도

`original_metrics_CURRENT.csv`에 CAGR·MDD·변동성·월간 Sharpe·기준자산10000을
보존했다. `comparison_metrics_CURRENT.csv`는 기존 CURRENT 결과를 연결한 표이며
새 성과 계산기는 없다. 장기간 누적자산·로그2축·드로우다운, 기간·비용·분위
선택과 명시적 KOSPI 가격지수 비교를 자체 포함 HTML로 제공한다.

기본 Net 고정비용 D02 최종자산15233.865271은 계수0.9에서15222.596921,
D08은16643.050705에서16625.089165가 된다. 일부2019 노출은 최종자산이 같아도
중간 드로우다운이 변한다. 정산1세션 지연은 이 전략의 거래 일정에서 NAV가 같았다.
이는 그 구간에서 유동성 제약이 비구속적이었다는 뜻이며 실제 입고일 인증이 아니다.
기본 모델은 이 성과를 보기 전 선택한 계약이고 우수 시나리오를 역선택하지 않았다.
단년 예시에서 CURRENT가 정의하지 않는 CAGR 등은 빈 값으로 유지했다.

## 재사용 가능 범위와 남은 공백

`scripts/research_workbench.py`의 capabilities/inventory/translate/check/run,
생성된 capability의 workbench/readiness 계약과 `docs/RESEARCH_WORKBENCH.md`를
사용한다. 제한된 한국어 항목 문법은 등록 별칭·상위N·10분위·월말·다음종가·
비용·벤치마크를 지원한다. 미해석 문구·중복·미지원 기능은 거부한다.
완전한 한국어 자유문장 지원으로 표시하지 않는다.

인벤토리에는1995~2026의32개 연도 파일이 있지만 이는 메타데이터다.
2007 법적 상장 이력이나 모든 종목의 기업행위 완전성이 인증된 것은 아니다.
2019~2020 전체 패널 진단 후보530개 가격불일치·217개 좌측검열·55개 우측검열은
실제 보유 노출과 분리했으며 자동 기업행위 등록·제외에 사용하지 않았다.
각 새로운 전략은 정확한 세션·lookback·벤치마크·보유1bp·기업행위·현금을 다시
검사한다. DART 재무 전략은 기존 availability/정정/기간/범위/PIT 게이트를 따른다.

2026-01-01~10-08 추가 준비도 질의는 XKRX4.13.2와 보존 관측값의6/3·7/17
불일치에서 먼저 차단되었다. 두 날짜가 실제 휴장인지 시세 누락인지는 공식
2026 현물 거래일 자료 확인 전 UNVERIFIED다. 평일 계산이나 채우기로 통과시키지
않았다. KOSPI 벤치마크도9/17까지만 있어 그 이후는 별도 공백이다.

현금배당·배당세·실제 단주 현금·증권사 입고·완전한 과거 법적 종목 이력·모든
공시 버전·시장영향의 역사적 사실은 인증하지 않았다. 다음 최소 작업은 새로운
요청을 준비도 검사에 넣고 실제 보유 첫 장애만 원천자료로 해결하는 것이다.
2020 말 권리를2021년으로 이어갈 때는 당시 승인·상장 원문이 필요하다.
실제 계좌 재현을 요청할 때만 계좌 입고·단주·원천징수 자료가 추가로 필요하다.
현재 완료한 연구 예시를 실행하기 위한 사용자별 계좌 자료는 필요하지 않다.

숫자 bytes 일치·실제 Chromium 기간/비용/분위/hover/zoom/모바일 검사를 필수

Actions 및 artifact execution.json/summary.json을 읽어 확인해야 하며, 이 문서가
커밋되었다는 사실로 CI 성공을 미리 선언하지 않는다.

첫 최종 CI39077759321/96a3785는 원래19명령·추가10명령·모든 실제 연구·
15개 숫자 파일 bytes/SHA·원본60·518/64 보존을 통과했으나 브라우저 단계에서

입력·검사 항목은 바꾸지 않았다. 수정 후 최종 CI를 같은 경로로 다시 실행한다.
