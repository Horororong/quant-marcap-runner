## 실제 개발 결과

`scripts/stock_dividend.py`에 전략 공통 **수량·권리·입고 제한 주식·현금 장부**를 구현했다.
배당락일 직전 계좌의 기존 주식만 권리를 얻는다. 당일 종가 신규 매수는 권리를 얻지 않으며,
권리 취득 후 기존 주식을 매도해도 계좌의 권리는 남는다. 조건부/승인된 권리를 구별한다.
실제 입고는 승인 권리를 미상장/매도불가 주식으로 옮기고, 별도의 실제 거래 가능 근거로만
매도 가능 수량에 편입한다. 입고·상장 전환 때 현금수익 또는1+배당률을 추가하지 않는다.

각 양의 미입고 권리는 해당 세션의 명시적 평가값·근거·가정이 있어야 한다.
보통주 종가나 승인확률을 기본값으로 사용하지 않는다. 단주 권리는 버리지 않지만
실제 단주현금·세금·부분 지급·취소/보상·차입·공매도·동일 종목의 중첩 기업행위는 미지원으로 차단한다.
입고에는 검증된 무차감 세무조건이 필요하다. 이는 실제 한국 투자자의 세금이0이라는 주장이 아니다.
실패한 세션의 거래·승인·입고·평가 변경은 원자적으로 취소된다. 재현 로그에는 입력과 근거가 남는다.

**목표비중 PROJECT 실행과의 연결은 미완료다.** 기존 실행기는 수량 대신 비중과 현금채권을 관리한다.
새 장부는 정수 주식 수량과 명시적 권리를 관리하며, 기존 비중의 분수 수량을 임의 반올림하거나
단주를 무시하면 원래 체결/비용 계약이 달라진다. 실제 사건 등록 전에 Gross/Net 장부·목표거래·비용·
유동성·단주/배정 정책·감사 출력의 통합이 필요하다. 새 전략별 백테스터는 만들지 않았다.
registry와 PROJECT는 `stock_dividend`를 명시적 capability_gap으로 계속 거부한다.
생성 capabilities에는 구현된 부분과 실행 미지원 경계를 함께 노출한다.

`validate_market_reference`는 공식 근거가 있는 기준가 대비 가격수익률을 별도로 검증한다.
기존1bp를 그대로 적용하고 기준가 역산을 하지 않는다. 경제적 장부가치는 현금+기존주식+
입고 제한 주식+평가된 권리다. ChangesRatio와 이 경제적 수익률의 동일성을 강제하지 않는다.
