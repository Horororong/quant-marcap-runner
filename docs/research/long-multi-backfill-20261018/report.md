## 회귀·CI·인계

보존849파일·518금융값·64핵심값·원문60건 중첩 member 검사는 PASS다.
기존151아카이브/211기준 파일·숫자 기준선은 덮어쓰지 않았다.2026의 과거 부정 검사를
공식 근거로 해소한 경우에만 executable_revision.json에 이전/이후 코드 SHA를 기록해
검사 기대값을 변경했다. 기존 성과·선정·NAV 기준값을 새 결과로 교체하지 않았다.

로컬 브라우저는 socket setsockopt 권한 오류/SIGTRAP로 실패했다. 추가 권한 요청은
사용자 취소로 실행되지 않았다. 이를 PASS로 표시하지 않으며, 최종 CI의 실제
Chrome 상호작용 결과가 별도 증거다. 새 source 수집 세 workflow는 과거 정확한 SHA에
고정했다. 최종 CI는 새 DART/KRX 수집 없이 고정 kit·기존 증거만 읽는다.

최종 커밋의 실제5개 검증 job와 아티팩트는 GitHub Actions에서 해당 SHA로 확인해야 한다.
이 문서의 로컬 PASS는 아직 실행되지 않은 원격 job의 PASS를 뜻하지 않는다.
최종 사용자 보고에는 실제 Run ID·SHA·job 결론을 별도로 제공한다.
재현 명령과 실패 복구 기록은 `reproduction.md`를 따른다.
