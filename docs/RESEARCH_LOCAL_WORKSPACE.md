# 로컬 연구 작업공간

기존 Strategy DSL → 준비도 → PROJECT 공통 엔진 → CURRENT 경로 위의 사용자
인터페이스다. 외부 모델은 연결되지 않았으며 제한된 한국어 규칙 문법만 지원한다.
모호하거나 미해석 조건은 실행하지 않는다. 모든 성과는 RESEARCH_ONLY이고
현금배당 총수익률·배당세 후 계좌·투자 PIT 인증을 뜻하지 않는다.

## 실행

기존 offline kit의 전용 Python과 `kit_manifest.json`을 먼저 검증한다.
검증된 kit의 코드는 변경하지 않고 프로젝트 코드만 별도 작업 복사본에서 실행한다.
아래 PY는 그 kit의 `.venv/bin/python` 절대경로다. 인터넷 pip 설치는 필요하지 않다.

```bash
"$PY" -I "$KIT/scripts/sandbox_runtime.py" verify
"$PY" -I scripts/research_web.py --store /absolute/new/research-store --port 8765
```

같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8765`를 연다. 클라우드 서버에서
실행한 localhost 주소를 사용자 PC에서 바로 열 수 있는 것은 아니다.
외부 공개 서버/인증/포트 전달은 이 로컬 실행 계약에 포함하지 않는다.
Windows에서는 원래 Linux kit의 검증된 실행 환경(예: 별도로 준비한 WSL)이
필요하다. Windows에 보관한 백업 ZIP만으로 실행 환경이 설치되지는 않는다.

1. 예제 또는 한국어 전략을 입력하고 조건 해석을 누른다.
2. 기간·모집단·선정·리밸런싱·체결·비용·기업행위 연구 계약을 확인한다.
3. 조건 확인 체크 후 자료 준비도를 검사한다.
4. 실행해 검증 NAV와 CURRENT 보고서를 연다. 실패는 원인과 필요한 자료로 표시된다.
5. 전략을 저장/불러오기 하거나 DSL JSON을 내보낸다.
6. 현재 DSL 기준 조건 수정 체크 후 `수수료를 2.5bp로 변경` 등으로 새 실행한다.
7. 성공한 실행 2~6개를 선택해 실제 전체 기간을 표시한 채 비교한다.

지원 예제는 시총10분위 2019~2020 전체, 모멘텀 상위3종목 2020 전체,
시총 상위1종목 2024 전체다. 2019~2025 사건연계10분위는 실제 미확인 권리
입력 때문에 차단되며 일부 기간 성공으로 표시하지 않는다.

## 계약과 저장

자연어는 등록된 단일 size 또는 명시적 3-1/6-1/12-1/12-0 모멘텀,
동일비중 top-N/10분위, 지정 월말·다음 거래일 이후 종가·고정 bp 비용을
해석한다. 손절·레버리지·임의 팩터/모멘텀 정의는 임의 대체하지 않는다.
중요 기본값은 해석 화면에서 표시하고 확인해야 한다. 외부 LLM 실증은 미완료다.

전략과 실행은 별도 ID로 추가 저장한다. 입력 변경 뒤 확인 해시를 재사용할 수 없다.
웹 전송 계약 v1.1은 브라우저의 정수형 JSON 직렬화를 해석 시점부터 반영한다.
2^53-1을 넘는 정수는 정확한 웹 전송을 보장할 수 없어 거부한다.
기존 엔진/CLI fingerprint·선정·비중·비용·NAV 계산은 변경하지 않는다.

`--store`에는 저장 전략, 작업 상태, 입력 DSL, worker 로그, 원래 엔진 산출물과
CURRENT 보고서가 남는다. 동시에 한 작업만 실행한다. 성공 NAV·보고서가 모두
확인된 경우에만 성공 보고서를 노출한다. 실패/중단 산출물은 성공으로 게시하지 않는다.

## 재현 검사

```bash
"$PY" -I -m unittest discover -s scripts -p test_research_language.py -v
"$PY" -I -m unittest discover -s scripts -p test_research_web.py -v
"$PY" -I scripts/test_research_workspace_e2e.py --output /absolute/new/e2e
```

E2E는 설치된 Chromium/Chrome과 Node 내장 CDP만 사용한다. 브라우저가 없으면
실패하며 자동 설치/모의 실행으로 대체하지 않는다. 세 실제 전략의 화면 실행,
저장·불러오기·JSON 동일 실행·수수료 수정·비교·미지원/실제 자료 차단을 검사한다.
자연어/JSON의 NAV·선정·목표비중·보유수익률 검사 바이트를 대조하고, 기존
Stage15 NAV 해시와 독립 원시가격·수량·권리·현금 장부를 재사용한다.
합성/표본/PIT 인증은 이 결과와 별개다. 실제 CI 상태는 해당 커밋의 Actions와
`actual-local-research-workspace` artifact에서 확인한다.

웹 전용 CI는 기준 `0552ad2` 이후 변경이 명시한 UI·전송·회귀·사용법 파일에만
한정되는지 검사한다. 금융 파서·원본·엔진 변경은 이 경로로 통과할 수 없다.
최초 게시 CI39425158415의 과거 Stage2 artifact 복원은
`503: Egress is over the account limit`로 실패했다. 같은 요청을 재시도하지 않는다.
이 웹 전용 검증은 pre-v8 금융 재처리/독립 감사의 대체 PASS가 아니다.
보존 원문60건의 외부 artifact 재다운로드 인증과 기존 금융값의 정확성 범위는
기존 감사에 남겨 두며, 웹 변경에서 이를 새로 인증했다고 표시하지 않는다.

후속 CI39425916256은 전략 제출 전에 `CDP timeout Target.createTarget`으로
실패했다. CI39426769934는 그 기존 3,591바이트 artifact만 읽어 진단했고
백테스트를 재실행하지 않았다. stderr의 D-Bus 메시지만으로 네이티브 원인을
확정하지 않는다. 브라우저 실행은 설치된 Chrome 우선 선택, GPU/기본 시작 탭
비활성화와 `Browser.getVersion` 준비 확인 후 타깃 생성으로 명시한다.
기존30초 CDP 제한·1200초 E2E 제한은 그대로다. 실패는 로그와 함께 실패로 남긴다.
