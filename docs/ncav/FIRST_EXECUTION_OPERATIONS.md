## Operating integration and verification boundary

Prepared workflow:manual only, false-by-default collection; exact checkoutSHA and
driverSHA; existing fixed kit; no Internet pip; no public artifacts/cache/raw.
Existing DART_API_KEY,KRX_AUTH_KEY,B_PRIVATE_BACKUP_TOKEN injection occurs only in
the collection step. No new credentials, paid service, schedule or public storage.

The adapter imports the existing main's GitHub control/private-store helpers.
It reads the existing shared histories, detects active finite collectors, checks
private access, and uses CAS writes into a **new separate grant** while preserving
all old budgets. An explicit private approved plan fingerprint is required.
No such approval has been installed. An existing source attempt in another grant
blocks recollection and requires reuse/review first.

Durable charge precedes each source request; raw preservation/readback precedes
success. CAS conflict/authentication/quota/access failures stop without retries.
Forced termination leaves SENDING/UNKNOWN; a prior runner may be reconciled only
after actual GitHub completion evidence, preserving consumed budget. UNKNOWN or
failed requests are never automatically resent. Only unrequested eligible keys
resume; immutable previously resolved task fingerprints cannot change/disappear.

All control setup and source work share the600-second deadline. Requests have a
15-second source timeout and reserve time for preservation. Actual completion
within two runs is **not measured** on live sources; a deadline records remaining
keys and cannot manufacture a third run. Zero eligible requests means NO_COLLECTION,
not completed collection. Responses, extracts, PIT admission and NAV are separate.

Verified locally: durable-before-source, CAS rejection, unchanged prior grants,
readback and fresh-root reuse, interruption without duplicate requests, deadline,
pagination/empty-response rejection, unapproved scope and endpoint guards.
Actual private repository read/push permission was readable; existing response
hashes matched. **No live CAS write, source request, remote CI, dispatch or merge
was performed.** Those need approval of the concrete transfer and private plan.
