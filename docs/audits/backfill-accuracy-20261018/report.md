또한비동기재생완료전에별도감사를시작해N10.json/Replays파일부재exit1이발생했다.
최종validate.py는의존명령을순차완료/종료코드검사한뒤다음단계를시작한다.
필수의존성누락은인터넷설치하지않았다. 실제HTTP requests수집통합은미실행이며,
60건은기존검증방식의금지된HTTPstub+정확한원문transport로실제파서/저장선택경로를시험했다.
이범위를실제네트워크수집인증으로표시하지않는다.

로컬최종validate --check는43금융unit,5서비스,5phase,6원문품질검사,
새24문서재추출/80독립통제,기존60재생/독립감사,518/64/849파일보존을완료했다.
main패치실제AST/적용·역적용은별도실행했다. CI는동일검사를실제실행하고
CSV/요약바이트일치를요구한다. 최종CI상태는보고서작성추정이아닌해당SHA의
GitHub Actions결과를최종채팅과artifact에서별도확인한다.
