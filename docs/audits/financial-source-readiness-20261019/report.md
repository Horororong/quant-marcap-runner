## 공통 결함과 남은 원문 문제

엄격 XML 검사에서 `<당기>`, `< 검토를 받지 아니한 재무제표>`,
`<LED 조명기기 제조 사업부문>`, `<2009년도 재고조사>` 같은 비태그 문자를
실제 태그처럼 해석했다. ASCII DART 구조/속성, CDATA·주석, 짝이 있는 태그는
그대로 두고, 명시적 문자 문법에 해당하는 한글 포함 꺾쇠만 구조 점검용 view에서
이스케이프한다. 원본 bytes·SHA·숫자·생산 숫자 파싱 입력은 바꾸지 않는다.
각 치환의 원문 문자 offset/문자열과 view SHA를 재현할 수 있다. 실제 불완전
태그·속성·숫자 비교식은 이 규칙으로 복구하지 않으며 실패 경계 시험을 추가했다.

110개 모두 원본 ZIP/CRC를 보존했다. 실제 원문 부재나 실제 재무표 부재로
새 인증한 문서는0이다. 남은 SOURCE_GAP9는1606/1656/1664/1665/1680/1682/
1690/1730/1745(모두2010033100 접두어)이며 미완성 꺾쇠·화살표·수식/기타
markup 문제가 남는다.1664는 정상 본문과 거부된 감사 member가 함께 있어
archive 전체 보류 정책의 영향도 명시한다. 이를 실제 자료 없음으로 표시하거나
감사 member를 임의 무시하지 않았다.1696은 천RMB 표/지원하지 않는 cover로
EXTRACTION_FAILED이며 환율을 추정하지 않는다. 표본·필드 범위 밖 CFS/계정의
누락까지 해결했다고 주장하지 않는다. source_classification에 모든 member의
SHA·엄격 진단·위치가 있다.52건 중 일부의 숫자 통제만으로 문서 전체를 PASS
처리하지 않는다.

## 사조 CFS·제일창업투자 OCF

검증된 고정 kit의 Actions39201336629에서 공식 조회6회, 원문 ZIP 신규 다운로드0회로
세 법인의 DART list(last_reprt_at=N,20100301–20100501,각1페이지)와 viewer를
보존했다. 응답 SHA/콘텐츠형/실제 조회시각은 publication-proof pack의 state.json이다.
웹 도구의 동일 viewer 접근은 inaccessible 오류였고 재시도하지 않았다. 인증된
Actions 경로로 전환했으며 키/키 포함 URL을 저장하거나 출력하지 않았다.

사조20100331001582 viewer의 att option은2010-04-30 `[추가]연결감사보고서`
dcmNo2651030 및 별도 연결제표 제출2651031을 명시한다. 공식 list에는
20100430001480 연결감사보고서도 있다. 원문의 감사 유효일2010-04-19는
공개일이 아니며 오기로 수정하지 않는다. 기존 ZIP CFS와 각 dcmNo의 직접 바이트
연결/전체 버전 그래프는 아직 미확인이다. CFS를3월31일 정보로 소급하지 않는다.
원문 CFS4개는 여전히 추출 coverage FAIL/숫자 UNVERIFIED다.

제일창업투자 본문2274870860원과 감사첨부2274103227원 OCF 차이767633원은
동일 FY2009/OFS/원의 CF 이익조정 차이와 같다. 공식 list는 별도 감사보고서
20100329000255와 사업보고서20100331001580을 확인하지만 어느 값이 해당 필드의
정정/대체 권위를 갖는지 입증하지 않는다. 임의 최신일 우선/평균/감사 우선 선택을
하지 않았다. CF 보류를 유지하며 독립 일치한 BS·IS3개를 함께 오염된 값으로
분류하지 않는다. 그3개도 공개시점·버전·역사 종목 연결은 별도 미인증이다.

## 검증 범위와 준비도

새 금융 통제는 기대 생산 값을 복사한 것이 아니라 독립 raw Grid의 명시적
주재무표·행·열·당기·단위 선택으로 고정했다.52개 목록을 먼저 고정했고, 추가
10건은 새 seed로 숫자 통제가 없던27개 문서 검토 집합에서 먼저 선정했다.
그10건은 형식 자체가 완전히 처음 보는 문서라는 주장이 아닌 새 숫자 holdout이다.
모든 원문은2010년 제출/FY2009 중심이므로 다른 연도 전체 정확성으로 확대하지 않는다.

financial_record_readiness는 숫자, 공개일, 버전, 역사 종목 연결, 신호일 가용성을
별도 판정한다. 금액·단위·법인·원문 member가 바뀌면 기존 attestation을 재사용할
수 없다. 공식 근거가 있는 완전한 달력만 다음 거래일 종가를 계산하며, 정정본
선택 후 현재 값이 불명확하면 오래된 값으로 돌아가지 않는다. 같은 날 정정/첨부
공개 전후 경계를 합성 시험했다. 합성 PASS를 실제 문서 인증으로 세지 않는다.
투자 운영 게이트나 기존 backtest_eligible=False를 바꾸지 않는다.

연구 브랜치의2010-04-30 실제 신호 조사에서 사조/고려반도체시스템의 원문 equity,
정규화 값, 당시 Marcap과 공통 B/P 산술이 독립 Decimal과 일치했다. 초기에는 역사
종목 연결·source-member 버전·공식 거래일 증거가 부족했다. 후속 공식 KRX4응답
(연구 CI39209874603)은2010-04-01과04-30의 두 시장 실제 거래·가격·Marcap을
확인했다.3월31일 바로 다음 민간 달력일4월1일의 실제 거래로 해당 공개일의
첫 다음 거래일을 입증하며, 전체4월/2010년 달력을 인증한 것은 아니다.
추가의 독립 신호일 증거와 공개 직후 달력 구간을 분리해 입력한다. 사조의 원문
법인명(법인형태 표기 제외)과 당시 공식 종목명이 정확히 일치하는 특정 시점 연결,
고려반도체의 축약 명칭 문제와 source-member 버전 증거를 구분했다. 후속 근거와
최종 개별 준비도는 연구 브랜치 보고서·실제 산출물을 따른다.1853 관측 거래
종목을 두 통제 종목으로 대체하지 않았고 전략 순위/선정은 승인하지 않았다.
기존 DART provider도2009Q3/FY 각각0/1495 준비도로 부분 모집단 실행을 거부했다.
세부 실제 산술/차단/공통 원인 묶음은 연구 브랜치 source-readiness-20261019에 있다.

단계는 reconciliation.json 비교에서 exit1로 실패했다. 실제110 canonical bytes와
두 원문 통제, 보호 검사는 통과했다. 게시 해시 수집의 glob 순서가 달라 JSON

동일/bytes만 다름을 확인했으며, 생성 순서가 반대인 디렉터리의 독립 회귀 시험과
정렬로 해결했다. 금융 통제·값·게시 파일 해시는 바꾸지 않았다. 최종 CI는 이
수정과 공개 경계 보강까지 같은 경로로 재검증한다.
