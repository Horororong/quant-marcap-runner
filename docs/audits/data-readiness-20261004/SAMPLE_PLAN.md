# 독립 재무 표본 선정 · 2026-10-04

성과/NAV 신규 실행 전에 고정한다. 수익률을 선정 기준으로 사용하지 않는다.

1. 이미 확보된 primary DART viewer 6개 공시(유나이티드 033270, 비츠로테크 042370, 대우중공업 000200, 피어리스 002130, 일동 000230, 대구백화점 006370)를 모두 포함한다. 제약: 기존 실패 조사 표본이며 무작위 전체시장 대표 표본이 아니다.
2. 각 공시에서 실제 당기·비교기간 heading과 unit을 읽고 OFS/CFS의 자본, 매출, 순이익/손실, OCF를 우선 점검한다. 그 외 차입금/감가상각과 전기 연간 항목을 포함해 최소 30개의 원문 금액과 해당 receipt/기간/scope의 저장 기록을 대조한다. 존재하지 않는 CFS·당기 OCF는 따로 자료 부족으로 기록한다.
3. 업종은 원문 회사 식별에 따라 제약, 전기기기, 중공업, 화장품, 유통으로 구분하되 업종 registry의 PIT 인증으로 쓰지 않는다. 비교 연도 1999/2000 및 회계연도 표기 2000/2001을 구분한다. 추가 확보 가능한 기존 원문에서는 저장값이 있는 사례와 정정공시를 포함한다. 확보하지 못하면 미검증으로 남긴다.
4. 같은 collector/parser의 재실행으로 expected value를 만들지 않는다. primary HTML 원문에서 literal cell·heading·단위와 offset/SHA를 보존하고 독립 audit 코드에서 단순 숫자 token만 비교한다. current/prior를 섞거나 공시일 이전 값을 인증하지 않는다.
5. 저장값 없음, 숫자 불일치, 기간/scope 불일치, 정정시점 미확인을 별도 상태로 집계한다. 30건 점검을 전체 데이터 인증이나 30건 수치 일치로 표현하지 않는다. 공시 접수일 확인도 전체 정정 chain의 인증은 아니다.
