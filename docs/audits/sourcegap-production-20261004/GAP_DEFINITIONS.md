API014 is NO_DOCUMENT for this endpoint, not proof of public absence. Parsing/unsupported-format/actual-scope-absence require primary evidence. Unknown format, unknown unit, fiscal-period ambiguity, semantic/account or column mismatch cannot be silently repaired.

PIT dimensions: actual displayed public family/date, original-publication identity, public clock, preserved historical source version, complete correction/value chain. A displayed date alone does not establish original publication or what value existed before a correction. Receipt prefixes and arbitrary lags are not availability evidence. Same-day before-close use cannot be proved without time evidence under the provider/next-close contract. Numerical matches never set PIT complete.

Data gaps (native damage, missing publication/version chain, missing periods/actions) and capability gaps (unregistered legacy/annual/TTM definitions) remain distinct.
