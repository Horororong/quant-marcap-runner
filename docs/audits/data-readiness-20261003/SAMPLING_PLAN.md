# 2026-10-03 원문 대조 표본 기준 (성과 확인 전 고정)

목표는 장기 백필 상태, 독립 데이터 품질, 실제 checked 백테스트 가능 범위 확인이다. 새 투자전략 선택·최적화, 보고 엔진/고정 실행 묶음 재생성은 범위 밖이다.

기준 main: 49afdcab324c2b778e21456e70a4e306feec4c0a. 로컬 출발 b82395e는 이전 보고 작업 branch이며 최신 main의 데이터와 같은 것으로 취급하지 않는다. 원격 작은 상태 파일을 기준 main ref로 별도 snapshot하고 Git blob/SHA 및 생성시각을 보존한다. 오래된 modern coverage 요약을 최신 상태로 사용하지 않는다.

표본은 기존에 확보한 12개 공시 원문 본문 전체를 사용한다. 성과·수익률로 고르지 않는다. 이 표본은 과거 원문/파서 실패 조사에서 선정된 위험 표본으로 대표성이나 무작위성을 주장하지 않는다. 이번 대조 결과에 따라 표본을 교체하지 않는다.

대상 접수번호: 20000809000052 (유나이티드, 의약품), 20000814000085 (비츠로테크, 전기장비), 20010103000052 (대우중공업, 중공업), 20010104000076 (피어리스, 화장품), 20010213000010 (당시 일동제약/저장명 일동홀딩스, 의약품), 20010213000014 (대구백화점, 유통). 업종은 사업 성격 설명이며 별도 검증된 과거 산업분류 필터가 아니다. 당시 명칭과 현재 저장명 차이는 숨기지 않는다.

필수 대조 항목: 각 공시의 별도 당기 자산총계·부채총계·자본총계·매출액·당기순이익/손실 5항목, 총 30건. 추가로 당기 영업현금흐름과 읽을 수 있는 연결 연간 제표를 점검한다. 단일행이 아닌 묶음 셀은 원문의 항목 순서와 금액 순서를 직접 확인하고 위치·literal cell을 보존한다. 연결 제표가 전기 연간이면 당기 분기와 섞지 않고 그 실제 연간 기간으로 별도 기록한다. 단위가 빈 경우 추정 환산하지 않는다.

원문 기준일은 2000-06-30/09-30/12-31, fiscal label은 비12월 결산 때문에 2000/2001이 섞인다. 연결 연간 비교에는 1999/2000 실제 결산일이 포함될 수 있다. 확보된 표본은 장기 전체의 여러 연도·업종 대표성 요건을 충족하는 인증 표본이 아니다. 현대 공시와 정정공시 확대는 새로운 원문 접근이 필요하며 접근 실패 시 차단됨으로 기록한다.

독립성: 실제 DART viewer 응답 원문 bytes의 SHA를 기존 capture 보고서와 확인한 뒤, 수집/금융 parser를 import하지 않는 HTML 구조 판독과 수동 지정 기대값을 사용한다. 같은 parser 재실행은 독립 검증으로 세지 않는다. 저장된 normalized 수치는 parser/source version, 접수번호, 기간, scope별로 대조하며 과거 버전·중복 값을 지우지 않는다. 원문은 있지만 저장값이 없으면 불일치 대신 저장 누락(data gap)으로 표시한다.

공시일은 저장 목록의 rcept_dt와 원문 viewer에서 실제 확인 가능한 정보의 증거 수준을 구분한다. 접수번호 앞 8자리만으로 독립 공시일 확인을 통과시키지 않는다. 정정 여부/관계·실제 공개 시각·전략 사용 가능일이 미확인이면 PIT 검증 미완료로 남기며 임의 시차를 채우지 않는다.

네트워크: 현재 Work는 proxy 연결 실패, DART 키/외부 identity 없음. 실패 명령은 10초 curl/60초 git 제한으로 종료했다. 동일 실패는 반복하지 않는다. 기존 GitHub connector 및 이미 확보한 원문을 재사용한다. 기존 예약 수집은 checkpoint 기반으로 계속 운영하며 별도 collector를 중복 시작하지 않는다.

단계별 산출물: main 상태/coverage snapshot → 원문 기대값·감사표 → 가격/유니버스/기업행위 점검 → 실제 checked runner/공식 CURRENT 검증 → 범위 표·로그·미해결 목록. 원자료·기존 체크포인트·고정 manifest는 변경하지 않는다.
