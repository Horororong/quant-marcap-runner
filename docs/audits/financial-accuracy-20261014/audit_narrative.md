## 독립 대조 방법과 분모

운영 재무 파서를 재실행하거나 생산자의 raw_amount/amount_reported를 정답으로 쓰지 않았다. 원본 XML의 보고서 표지·AREgCIK·재무제표 제목·기간·단위를 직접 읽어 manual_controls.json에 표별 통제값을 기록했다. 별도 표준 라이브러리 HTMLParser는 TD/TH/TE/TU의 원문 텍스트·속성과 표 좌표만 보존한다. 생산자 좌표는 원문을 찾는 locator로만 사용한다. 기대 숫자는 원본 현재 열/정정후 표의 셀에서 읽고, 독립 Decimal 문법으로 부호와 단위를 정규화했다. 원본 ZIP40개 전체의 기대 SHA256·CRC 및 XML member SHA256을 다시 검사했다.

원본들은 기존 수집 artifact에서 확보한 DART native XML이다. 보존 원본과의 일치를 확인했으며, 별도 실시간 DART 재다운로드나 XBRL 이중 인증을 했다고 주장하지 않는다. 원본 그림 속 숫자의 OCR은 하지 않았다.

금액 허용 오차는 0원이다. 원1·천원1,000·백만원1,000,000·억원100,000,000. 원문 괄호·(-)·△·마이너스는 음수, 순손실 전용 계정의 양수 표기는 손실로 정규화한다. 이익(손실) 선택 계정명은 숫자 자체의 부호를 유지한다. 대시를 0으로 추정하지 않으며 현재 그룹에 표시 숫자가 없는데 과거 열을 선택하면 현재 열 FAIL로 기록한다. 현재 그룹 내 세부/합계 칸 또는3개월/누적 숫자는 헤더의 colspan으로 기간 그룹을 제한하고, 3개월/누적 여부의 부족한 저장 메타데이터는 별도 UNVERIFIED다.

## 검증불가·투자 사용 결론

원본40건은 모두 확보·해시검증·본문검토했지만 **모든 요청 항목이 검증된 것은 아니다.** AREgCIK는40건 일치했으나 과거 종목코드/사명변경의 독립 공식 이력을 확보하지 못해 종합 identity는 UNVERIFIED다. 현재명과 공시 당시 이름 차이만으로 기업 불일치라고 단정하지 않았다.

S24/S39/S40의 정정전 선택은 FAIL, 그 외 전체 원공시/정정 접수 체인의 독립 확보가 없어 corrections를 UNVERIFIED로 남겼다. 전략의 실제 과거 신호 기준일·원문 최초 공개시각·수정 이력도 확보하지 못해 PIT40건 전부 UNVERIFIED다. 회계종료일이나 접수번호 날짜를 공개시각의 증명으로 대체하지 않았다. 향후 확정된 제출시각/수정체인·실제 백테스트 신호일로 다시 검증해야 한다.

**현재 신규 legacy 데이터를 실투자 백테스트의 재무 팩터 입력으로 사용하기에는 부적합하다.** 숫자·기간·범위·버전 오류가 확인됐고 시점 정보도 미검증이다. 별도 제공자/다른 기간까지 이 결론을 확대하지 않으며 전략 CAGR이나 수익률도 인증하지 않는다. 이 보고서는40건의 독립 원문 대조 결과이며 전체 금융기관 감사 인증이 아니다.
